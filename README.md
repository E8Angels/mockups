# E8 Mockups

Static HTML design mockups and prototypes for the [E8 portal](https://github.com/E8Angels/e8-portal).

Browse the live index: **https://e8angels.github.io/mockups/**

Each file is a self-contained HTML prototype. All seed data is fictional — names, companies, dollar amounts, and dates are placeholders for design review only.

## Adding a new mockup

1. Drop the `.html` file in this directory.
2. Add an entry to the `FILES` array in `index.html`.
3. Commit and push — GitHub Pages auto-deploys from `main`.
