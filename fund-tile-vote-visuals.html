Fund tile — vote visualization ideas

Current ballot tile uses a stacked bar + percent legend. The bar reads as a progress bar, not a distribution of votes. Five alternatives below — same data, different framings.

The Claude superpower to invoke here: ask me to build an interactive HTML comparison page like this one. Side-by-side variants with real hover states let you feel which one clicks in 2 seconds versus which needs explaining. Static Figma frames can't do that. For any UI decision where "is this legible?" is the question, a live mockup beats a description.

Option 2 · human

Dot per member (waffle chart)

Each dot = one real human voting. Empty dots = haven't voted yet — surfaces turnout AND distribution in one visual. Very "community" in tone. Hover a dot to highlight that member.
