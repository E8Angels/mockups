Live values

Insert these tokens in any question label; members see the resolved value.

{company} → the pitching company's name

{min check size} → deal-terms minimum check, e.g. “$10,000”. Empty if none.

Tips
  • Conditional questions can only depend on an earlier question.
  • A question hidden by role/vintage targeting is skipped, not just disabled.
  • Reorder with the ⋮⋮ handle; order is how members see them.
