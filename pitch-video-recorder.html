Updated decisions

Applicant dashboard. "Record Pitch" button sits inside the Current Application card, next to "View Application". Amber→red gradient button treatment (it pops without needing a "NEW" pill). Instructional copy ("10-minute pitch... due May 2") appears below the button stack. Only renders when applications.pitch_video_invited = true.
Screening page. Request Recording entry points live where the real Screening page already puts actions: (1) Per-card icon button in the card action row (alongside Notes, Refer Out, Pitch Deck). Dot indicator: empty = not requested, amber = sent, green = received. (2) Header-level Request Recordings button next to Rate / Stack Rank / Release Ratings. Implicitly applies to everyone currently in ?stage=Screening — modal copy says so. No explicit row-selection UI.
Committee viewer. New inline Pitch Video section inside the expanded screening-list card (where you already see About the Company / Team / Investment Details). Not a new tab or page. Three layout modes (video-over-deck / floating PiP / side-by-side). Fullscreen button. Transcript panel on the right, searchable, click-to-jump. Slide strip below the player.
No "Folder / Team / Emails" tabs. Those belong to the diligence application-review context, not screening. The screening page is a list-of-expandable-cards with inline section rendering — our mockup now matches.
No bulk row-selection UI. Clarified per Jordan: Request Recordings from ?stage=Screening implicitly applies to all companies currently in that stage. Modal copy calls this out. Skips anyone already sent-to / received-from.

Unchanged from previous plan

  • Storage: raw camera video + deck PDF + sidecar JSON + transcript JSON. No stitched MP4 in v1.
  • PDF only (no PPTX in v1).
  • Cloudflare Stream for hot storage → Drive for cold archive after the screening meeting.
  • 10-min target, 12-min hard cap.
  • Two email templates: request_recording, pitch_video_reminder. Seed script supports --env=prod.
  • Whisper transcript on submit.
  • Upload-as-you-go for crash safety.
  • Schema sketch: new pitch_video_recordings table + applications.pitch_video_invited column.
