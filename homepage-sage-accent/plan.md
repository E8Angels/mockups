# Homepage — Sage Accent

## Background

A color exploration for the e8angels.com homepage. `mockup.html` is a static, self-contained snapshot of the current homepage with the brand accent swapped to sage (`#8BA88E`) — used for the teal accent token, link underlines, and highlight elements — so the team can judge the change on real content.

## Proposed UX

- No layout or copy changes; only the accent color changes from the current teal to sage `#8BA88E`.
- A sibling exploration uses a terracotta accent (`#C47055`); compare the two before choosing.

## Open questions

- Does sage hold enough contrast on the cream and white sections, especially for small text and link underlines?
- Should sage replace the accent site-wide, or only on the homepage?
